# Explanation 

This script logs into a Telegram account, fetches all participants from a specified Telegram channel or group, and saves their details (like username, first name, last name, etc.) into a JSON file. The use of asynchronous programming with asyncio and Telethon allows it to efficiently handle the potentially long-running process of fetching participants.

## output 
The output will be JSON file which will be opened using a converter or a third part viewer.
